GateBoard

A bounty board where your Agent ID is the key.

Anyone can read the board. Only wallets holding a Binance Agent ID — a name.ai — can post or claim a bounty. That rule isn't a setting on this page: the GateBoard contract checks balanceOf on the Agent ID contract before it accepts any write, so a wallet without an Agent ID simply cannot get in.

How it works

1

Claim your name.ai

In the Binance App: Wallet → homepage banner → Agent ID. One per user, non-transferable, claimed once and yours. That's the whole sign-up — there is no GateBoard account.

2

Connect & get checked

Connect your wallet above. GateBoard calls balanceOf on the Agent ID contract (0x60b9…022f). More than 0 and the gate opens; 0 and posting stays locked.

3

Post or claim on-chain

Posting and claiming are contract calls, confirmed by you in your wallet. The poster marks a claimed bounty done; the reward itself moves off-chain, wallet to wallet.

Deploy checklist

GateBoard.sol is written and ready. These are the steps to take it live — all doable from a phone with Remix and the Binance Wallet.

  1. Open GateBoard.sol in RemixThe contract source is in the project folder (hackathon-binance-gateboard/GateBoard.sol). Paste it into a new file in Remix.
  2. Compile with Solidity 0.8.20 or laterNote the exact compiler version and optimizer setting you use — BscScan verification must match them.
  3. Deploy on BNB Chain mainnet (chain 56)Constructor argument is the Agent ID contract: 0x60b9262456de011f7d15a54cdd8c48baaa8b022f. Deploy from the wallet that holds your Agent ID, with a little BNB for gas.
  4. Verify the source on BscScanSame source, same compiler settings, constructor argument encoded. The listing must show the code as verified and open-source — that's a hackathon requirement.
  5. Point this page at the contractPaste the deployed GateBoard address into GATEBOARD_ADDRESS at the top of this page's script and republish. The board switches from preview to live reads and writes.
  6. Seed the boardPost 2–3 real bounties from your Agent ID wallet so the first visitors see a working board, not an empty one.
  7. Push for 30 Agent ID addressesShare the invite post below. Every distinct Agent ID holder who posts or claims counts toward the Innovation Award bar — and toward the on-chain activity track.
  8. Submit before 9 Dec 2026, 08:00 UTCProject name, this page as the website, the GateBoard contract address, and the Agent ID usage description — the submission blurb below is ready to paste.

Submission blurb

GateBoard — Agent ID-gated bounty board (BNB Chain) GateBoard is a bounty board where an Agent ID is not a badge but the write permission itself. The GateBoard contract checks balanceOf on the official SPACE ID Agent ID contract (0x60b9262456de011f7d15a54cdd8c48baaa8b022f) inside createBounty() and claimBounty(), so a wallet without a name.ai cannot post or claim, while anyone can read the board. There is no owner, admin, fee, or custody: the contract holds no funds, and payment for completed work is arranged off-chain between poster and claimer. Agent ID usage: identity + access control. Your name.ai is your account — no sign-up, no password, no server session.
